Developed a healthcare DApp prototype using HTML , Tailwind CSS & JavaScript, featuring an AI powered assistant for disease prediction and recommendations via the Gemini API
A conceptual front-end prototype demonstrating a Decentralized Application (DApp) for healthcare. This project focuses on simulating secure patient data management and leveraging Generative AI (Google Gemini) for intelligent support, diagnosis, and personalized medical recommendations.

The entire application is built as a single, self-contained HTML file for maximum simplicity and ease of deployment.

✨ Key Features
This prototype showcases a hybrid stack, combining front-end development with powerful cloud-based AI services.

Simulated DApp Authentication: Demonstrates the user flow of connecting a wallet (instead of traditional login) and defining a user role (Patient or Doctor).

Conceptual Data Upload: Simulates the secure, immutable upload of key patient metrics (symptoms, vitals, history), representing a transaction on a decentralized ledger.

AI-Powered Data Summarization: Uses the Gemini API to analyze raw patient data and generate a quick, concise summary for a reviewing physician.

AI Disease Explanation: Generates easy-to-understand explanations of predicted diseases for patients, increasing health literacy.

Intelligent Recommendations: Utilizes the Gemini API's structured output capability to provide targeted recommendations for the required specialist (Doctor) and facility (Hospital).

Conversational AI Assistant: A general-purpose chat interface powered by Gemini to answer quick health-related questions.

🛠️ Technology Stack
This project was intentionally built with a lightweight, client-side stack to eliminate complex build processes and dependencies.
TECH STACK
[1] Front-End
HTML5 / JavaScript (Vanilla)
Structure, client-side logic, and event handling.
[2] Styling
Tailwind CSS (via CDN)
Responsive, modern, and utility-first styling.
[3] AI Engine
Google Gemini API (gemini-2.5-flash-preview-05-20)
Powers all generative features (summaries, explanations, recommendations, and chat).
[4] Architecture
Single-File Application

All code is contained within one file (.html), requiring no local dependencies to run.

💡 Conceptual Blockchain Core
It is important to note that this is a prototype. While it does not connect to a live blockchain network, it demonstrates the core concepts:

Decentralization: Simulates the patient owning and controlling their health data.

Immutability: The data is "uploaded" and remains fixed, simulating a permanent record on the ledger.

Smart Contract Logic: The Prediction and Recommendation features represent calls to automated code (Smart Contracts) that would execute on the blockchain.
